# Daily review workflow

## Purpose

Create a faithful synthesis of one day's entries. Compress repetition while preserving tensions, changes, and unfinished thoughts.

## Procedure

1. Confirm the target date and selected sources.
2. Read the entries in chronological order.
3. Extract events, stated reactions, decisions, ideas, and intended actions.
4. Group related material into a small number of themes.
5. Identify a change only when the day's sequence or an explicit comparison supports it.
6. Track intended actions without assuming later execution.
7. Draft the review, then check every analytical claim against source evidence.

## Output sections

Use only sections supported by the source, in this order:

1. **Daily overview** — a compact account of the day's central thread.
2. **Main themes** — the important clusters of events or attention.
3. **Key insights** — the writer's expressed realizations plus clearly labeled analytical observations.
4. **New ideas** — ideas first appearing that day.
5. **Shifts in thinking** — a before/after contrast with evidence.
6. **Open follow-ups** — intentions, questions, or commitments without completion evidence.
7. **Overall thread** — how the supported elements connect.

Do not create an empty review. If no substantive entry exists, report that the day has no analyzable material and stop before saving.
